# 数据库与SQL知识库 RAG 智能问答系统

## 项目简介
本项目是一套面向数据库与SQL领域的**检索增强生成（RAG）智能问答系统**。针对大模型专业知识幻觉问题，通过向量检索+大语言模型的架构，实现了知识库上传管理、语义精准检索、可溯源专业回答的完整链路。系统支持本地知识库持久化、多轮上下文对话、回答来源标注，可作为垂直领域知识助手使用。

## 技术栈
- **Web框架**：Streamlit
- **RAG框架**：LangChain
- **向量数据库**：Chroma（本地持久化存储）
- **嵌入模型**：通义文本嵌入 v4
- **大语言模型**：通义千问 qwen3-max
- **数据存储**：本地JSON（对话历史）、MD5哈希（内容去重）

## 核心功能
1. **知识库管理**：支持TXT格式知识文档上传，自动完成文本解析、切分、向量化入库
2. **智能内容去重**：基于MD5哈希校验文件内容，重复上传自动跳过，避免资源冗余
3. **精准语义检索**：优化文本分块策略，默认返回Top3相关文档片段，保障回答完整度
4. **可溯源问答**：约束模型严格基于知识库回答，回答末尾自动标注参考来源，有效降低幻觉
5. **多轮对话**：本地持久化存储对话历史，支持上下文关联的连续问答
6. **自动分类标签**：根据文件名自动提取知识分类，便于知识库结构化管理

## 技术亮点
1. 基于LangChain搭建完整RAG执行链路，实现「文本加载-语义切分-向量化存储-向量检索-提示词组装-模型生成」全流程自动化
2. 针对数据库知识点特性优化文本切分策略，调整块大小与重叠长度，兼顾检索精度与语义完整性
3. 封装Chroma向量数据库服务，实现本地持久化存储，支持知识库增量更新与快速检索
4. 设计并实现MD5内容去重机制，从文件维度避免重复数据入库，提升向量库空间利用率
5. 通过Prompt Engineering构建专业领域提示词模板，规范输出格式，强制回答溯源，显著提升专业内容准确率
6. 基于Streamlit实现轻量化Web交互界面，支持流式输出、加载动画，交互体验流畅
7. 自定义实现本地文件版对话历史管理器，兼容LangChain标准接口，支持会话级历史持久化

## 项目结构
```
RAGPROJECT/
├── app_file_uploader.py    # 知识库上传Web页面
├── app_qa.py               # 智能问答Web页面
├── config_data.py          # 全局配置（切分参数、模型、向量库配置）
├── knowledge_base.py       # 知识库核心服务：切分、去重、向量入库
├── rag.py                  # RAG问答核心：检索链、提示词、对话链
├── vector_stores.py        # 向量数据库服务封装
├── file_history_store.py   # 本地对话历史管理
├── data/                   # 示例知识库文件
└── chroma_db/              # 向量数据库本地存储（自动生成）
```

## 快速运行
1. 安装依赖
```bash
pip install streamlit langchain langchain-community langchain-chroma chromadb
```
2. 配置环境变量 `DASHSCOPE_API_KEY` 为你的API密钥
3. 启动知识库上传页面：`streamlit run app_file_uploader.py`
4. 启动智能问答页面：`streamlit run app_qa.py`
